# RetroCollection — descargas

Apps de RetroCollection para **Windows** y **Android**. Abren la web de RomM de RetroCollection y añaden **«Jugar en local»**: el juego se abre en RetroArch con el núcleo adecuado, con logros de RetroAchievements (también Hardcore), y las partidas se sincronizan con RomM antes y después de jugar.

Este repositorio solo contiene las versiones publicadas.

## Descargar la última versión

- **Windows 10 y 11:** [RetroCollection-Windows-setup.exe](https://github.com/sonycrow/retrocollection-app-releases/releases/latest/download/RetroCollection-Windows-setup.exe)
- **Android 8 o superior:** [RetroCollection-Android.apk](https://github.com/sonycrow/retrocollection-app-releases/releases/latest/download/RetroCollection-Android.apk)

Todas las versiones: [Releases](https://github.com/sonycrow/retrocollection-app-releases/releases).

## Instalar

- **Windows:** ejecuta el instalador. Windows puede avisar de «editor desconocido»: pulsa «Más información» y «Ejecutar de todas formas».
- **Android:** abre el APK y permite instalar apps de origen desconocido cuando te lo pida.

Necesitas **RetroArch** instalado y una cuenta en la web de RetroCollection.
